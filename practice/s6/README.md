# S6 — Diseñar y liderar

## Theme

**Systems thinking**

## Focus

Arquitectura avanzada, producto, documentación, liderazgo técnico, IA aplicada, investigación y proyecto final.

## Estructura

- 16 clases principales.
- Mentoría aproximadamente cada 2 semanas.
- Trabajo autónomo entre clases.
- Proyecto longitudinal.
- Milestone al finalizar.

## Proyecto

Diseñar, construir, operar y defender una evolución significativa de un sistema real, con arquitectura, roadmap, evidencia y decisiones documentadas.

## Regla pedagógica

La clase introduce una capacidad. El proyecto obliga a usarla en contexto. La mentoría revisa decisiones. El milestone evalúa integración.

## Clases

- **01** — De requisitos a arquitectura
- **02** — Architecture Decision Records
- **03** — Threat modeling
- **04** — Reliability engineering
- **05** — Evolutionary architecture
- **06** — Legacy y refactoring estratégico
- **07** — Domain-driven design práctico
- **08** — Product thinking para developers
- **09** — Métricas de producto y tecnología
- **10** — Documentación técnica como sistema
- **11** — IA para ingeniería de software
- **12** — Agentes, automatización y revisión
- **13** — Investigación técnica y evaluación
- **14** — Comunicación y liderazgo técnico
- **15** — Proyecto final: arquitectura y roadmap
- **16** — Defensa del proyecto final

## Milestone

**M-S6 — Proyecto final**

La calidad se evalúa por evidencia y capacidad de explicación, no por cantidad de código ni por cantidad de tecnologías utilizadas.
