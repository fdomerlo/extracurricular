# Semester 01 — Construir

Primera implementación piloto del curriculum.

## Objetivo

Aprender a construir software pequeño pero correctamente estructurado, reproducible, testeable y mantenible.

El semestre utiliza Python como lenguaje principal, Git como sistema de colaboración y un proyecto longitudinal como contexto de aplicación.

## Resultado esperado

Al finalizar S1 el estudiante debe poder:

- modelar un dominio pequeño;
- implementar reglas de negocio;
- estructurar código modular;
- manejar errores;
- escribir tests;
- utilizar Git profesionalmente;
- proponer cambios por Pull Request y revisar código;
- depurar sistemáticamente;
- reproducir el entorno;
- utilizar IA como tutor/revisor sin delegar la responsabilidad.

## Duración

22 semanas lectivas, como todos los semestres (`curriculum/study-plan.md` §5): 15 de
contenido, 1 de recuperación, 2 de integración, milestone, defensa, buffer y cierre.
El detalle está en [`schedule.md`](schedule.md).

## Clases

**11 clases**, listadas en [`class-catalog.md`](class-catalog.md). El contenido vive en
[`classes/`](classes/) y es la fuente de verdad.

S1 no usa módulos: con 11 clases, agrupar en submódulos etiqueta más de lo que organiza.
El mismo criterio que S2–S6.

> **Nota sobre la estructura.** S1 es el único semestre con contenido de clase realmente
> autorado; S2–S6 tienen archivos de clase con estructura de plantilla y sin contenido
> escrito. La diferencia entre S1 y el resto no es de *forma* sino de *estado de autoría*.

## Proyecto

El estudiante utiliza un proyecto propio o el Reference Project si no dispone de uno.

## Regla del semestre

> Primero hacemos que funcione. Después demostramos que funciona. Finalmente demostramos que podemos mantenerlo.
