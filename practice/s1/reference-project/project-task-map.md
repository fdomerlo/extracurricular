# Reference Project — Task Map

Qué aporta cada clase de S1 al Reference Project (sistema de turnos, dominio en memoria).

| Clase | Aplicación |
|---|---|
| S1-01 | Preparar el entorno e inicializar el historial |
| S1-02 | Escribir el primer valor del dominio con type hints y dataclasses |
| S1-03 | Diseñar la jerarquía de excepciones del dominio |
| S1-04 | Identificar Patient, Professional, Practice y Appointment como entidades o valores |
| S1-05 | Implementar las reglas de Appointment (solapamiento, duración, cancelación, sobreturno, feriados) |
| S1-06 | Automatizar la verificación de esas reglas con pytest |
| S1-07 | Integrar un cambio desde una rama y resolver un conflicto real |
| S1-08 | Diagnosticar un defecto deliberado con `breakpoint()` |
| S1-09 | Reproducir un defecto a partir de un reporte vago, con test rojo previo |
| S1-10 | Abrir el PR del arreglo y revisarlo antes de integrarlo |
| S1-11 | Usar IA y verificar su resultado contra el comportamiento real |
