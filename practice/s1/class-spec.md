# Class Specification

## Estructura

```text
Contexto
→ Concepto mínimo
→ Demostración
→ Laboratorio
→ Ejercicio
→ Challenge
→ Project Task
→ Evidencia
```


## Objetivos

Entre 2 y 5 objetivos observables.

## Concepto mínimo

Solo la teoría necesaria para realizar la práctica. La profundización pertenece a `theory/`.

## Demostración

Ejemplo pequeño, ejecutable y modificable.

## Laboratorio

Reproducción y modificación del ejemplo.

## Ejercicio

Variante que no pueda resolverse copiando la demostración.

## Challenge

Introduce una decisión y exige justificarla.

## Project Task

Aplicación al proyecto propio o Reference Project:

1. identificar el problema;
2. proponer solución;
3. implementar;
4. agregar evidencia;
5. documentar decisiones.

## IA

Declarar explícitamente qué uso está permitido.

Regla:

> El estudiante debe poder explicar, modificar y verificar todo código incorporado.

## Evidencia

Puede ser:

- commit;
- test;
- benchmark;
- ADR;
- PR;
- demo;
- explicación.

## Definition of Done

- [ ] funciona;
- [ ] es ejecutable;
- [ ] el estudiante puede explicarlo;
- [ ] puede modificarlo;
- [ ] existe evidencia en Git.
