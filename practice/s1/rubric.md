# M-S1 Rubric

| Dimensión | Excelente | Aceptable | Insuficiente |
|---|---|---|---|
| Dominio | Modelo claro y reglas explícitas | Modelo funcional | Reglas incorrectas |
| Código | Modular y legible | Funcional | Acoplado |
| Tests | Protegen comportamiento crítico | Casos principales | Superficiales/ausentes |
| Debugging | Reproduce y explica causas | Corrige bugs | Corrige sin comprender |
| Git | Historial claro | Utilizable | Desordenado |
| Reproducibilidad | Cero pasos implícitos | Parcial | Solo funciona localmente |
| Decisiones | Evalúa alternativas | Justifica elección | No puede justificar |
| Comunicación | Defensa precisa | Explica lo principal | No puede defender |
