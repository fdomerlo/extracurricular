# S5 — Producción

## Theme

**Production engineering**

## Focus

Cloud, infraestructura como código, seguridad avanzada, supply chain, backups, recuperación y operación.

## Estructura

- 16 clases principales.
- Mentoría aproximadamente cada 2 semanas.
- Trabajo autónomo entre clases.
- Proyecto longitudinal.
- Milestone al finalizar.

## Proyecto

Operar el sistema como un servicio real: infraestructura reproducible, seguridad, backups, observabilidad y recuperación.

## Regla pedagógica

La clase introduce una capacidad. El proyecto obliga a usarla en contexto. La mentoría revisa decisiones. El milestone evalúa integración.

## Clases

- **01** — Sistema operativo y runtime de producción
- **02** — Redes para aplicaciones
- **03** — Cloud: compute, storage y networking
- **04** — Infrastructure as Code
- **05** — Provisioning reproducible
- **06** — Secrets y gestión de identidades
- **07** — Supply chain y dependencias
- **08** — Hardening de aplicaciones
- **09** — Backups y recuperación
- **10** — Disaster recovery
- **11** — Observabilidad operacional
- **12** — Incident response
- **13** — Costos y capacidad
- **14** — Release engineering
- **15** — Operación de producción
- **16** — Milestone: servicio productivo

## Milestone

**M-S5 — Servicio productivo**

La calidad se evalúa por evidencia y capacidad de explicación, no por cantidad de código ni por cantidad de tecnologías utilizadas.
