# S3 — Entregar software

## Theme

**Build and ship**

## Focus

HTTP, frontend, integración full-stack, CI/CD, contenedores, despliegue y prácticas de entrega.

## Estructura

- 17 clases principales.
- Mentoría aproximadamente cada 2 semanas.
- Trabajo autónomo entre clases.
- Proyecto longitudinal.
- Milestone al finalizar.

## Proyecto

Convertir la aplicación de S2 en un producto full-stack desplegado mediante un pipeline reproducible.

## Regla pedagógica

La clase introduce una capacidad. El proyecto obliga a usarla en contexto. La mentoría revisa decisiones. El milestone evalúa integración.

## Clases

- **01** — HTTP como protocolo
- **02** — HTML, CSS y accesibilidad
- **03** — JavaScript esencial para la web
- **04** — Arquitectura de interfaz de usuario
- **05** — Estado en la interfaz
- **06** — Integración frontend/backend
- **07** — UX para productos técnicos
- **08** — Testing de frontend
- **09** — Empaquetado reproducible de la aplicación
- **10** — Orquestación de servicios locales
- **11** — CI: automatizar calidad
- **12** — CD y releases
- **13** — Secrets y configuración de producción
- **14** — Proxy inverso y HTTPS
- **15** — Deploy de una aplicación
- **16** — Operar una release
- **17** — Milestone: producto desplegado

## Milestone

**M-S3 — Producto desplegado**

La calidad se evalúa por evidencia y capacidad de explicación, no por cantidad de código ni por cantidad de tecnologías utilizadas.
