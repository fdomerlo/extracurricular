# Reference Project — Task Map

| Clase | Aplicación |
|---|---|
| S3-01 | Inspeccionar el tráfico real de la aplicación de S2: métodos, códigos de estado, cookies de sesión |
| S3-02 | Maquetar las vistas de reserva de turno: HTML semántico y accesible |
| S3-03 | Agregar la interactividad mínima de cliente que HTMX no cubre (validaciones, pequeños comportamientos de UI) |
| S3-04 | Definir cómo se organizan las plantillas y fragmentos server-rendered de la vista de reserva |
| S3-05 | Manejar el estado de la reserva (turno seleccionado, formulario en curso) entre swaps de HTMX |
| S3-06 | Integrar la vista de reserva con la capa de persistencia de S2 |
| S3-07 | Diseñar el flujo de reserva desde la perspectiva del paciente ficticio |
| S3-09 | Empaquetar el proyecto en una imagen reproducible |
| S3-10 | Levantar aplicación + base de datos con un solo comando |
| S3-13 | Gestionar secrets y configuración distinta entre desarrollo y producción |
| S3-14 | Configurar proxy inverso, TLS y dominio para el despliegue |
| S3-15 | Desplegar el sistema en un servidor real |
| S3-16 | Operar una primera release: logs, reinicio, backups automatizados |
| S3-17 | Milestone: sistema desplegado y usable fuera de tu máquina |
