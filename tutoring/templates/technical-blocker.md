## 4. Checklist de Diagnóstico Previo (Rubber Ducking)

*Marcá con `[X]` las acciones que realizaste antes de enviar esta consulta:*
- [ ] Leí el traceback completo e identifiqué el archivo y línea exacta donde se originó el error.
- [ ] Intenté aislar el fallo en un script mínimo independiente con datos de prueba simples.
- [ ] Consulté la documentación oficial de la función o librería involucrada.
- [ ] Agregué `print`, usé el debugger (`pdb` o IDE) o escribí aserciones para inspeccionar el estado de las variables.
- [ ] Si usé un asistente de IA, no resolvió el problema o no comprendí la solución que me ofreció.
